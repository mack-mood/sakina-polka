# Rare Polka

p5.js sketch set up to run full screen on an iPad.

Hold one finger on the screen for 4 seconds to start the black hole. Let go to hear the sound.

## What is in this folder

- index.html: the page. It has the full screen settings and the "tap to start" screen.
- sketch.js: the sketch, not changed.
- sound.mp3: the sound.
- manifest.json: tells the iPad to open it as a full screen app.
- icons: the Home Screen icon in different sizes.
- style.css, p5.js, p5.sound.min.js: from the p5.js Web Editor download, not changed.

## Put it online

1. Upload everything inside this folder to a public GitHub repository.
2. Settings --> Pages --> Deploy from a branch --> main --> / (root) --> Save.
3. Wait 1 to 3 minutes. Your link is at the top of the Pages screen.

## Put it on the iPad

1. Open the link in Safari.
2. Share --> Add to Home Screen --> Open as Web App on --> Add.
3. Open it from the Home Screen icon, then tap to start.
